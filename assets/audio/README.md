# Audio Assets

## U4 Peace yard

Git tracks three audio files in this folder:

- Bed (loop): `assets/audio/peace_yard_bed.ogg` — quiet two-partial drone.
- Well sting: `assets/audio/peace_well_sting.ogg` — soft short triad on existing well Use.
- Combat hit: `assets/audio/combat_hit.ogg` — soft thud on a landed strike (COMBAT-FEEL-SFX-1). Source: Kenney, "Impact Sounds" `Audio/impactSoft_medium_001.ogg`, https://kenney.nl/assets/impact-sounds, licence CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/), downloaded 2026-11-02. Re-encoded from the stereo original (identical channels) to mono Vorbis, −3 dB: `ffmpeg -i impactSoft_medium_001.ogg -af "pan=mono|c0=c0,volume=-3dB" -c:a libvorbis -q:a 4 combat_hit.ogg` (4265 B, 0.18 s, peak −4.0 dBFS). Not generated by the script.

The lived mixer loads only those two (`shared/peace_audio.rs` `BED_ASSET` and `STING_ASSET`); combat loads the hit (`client/src/combat_core.rs` `HIT_ASSET`). Heartwood and Depths reuse the yard bed at a lower gain. Generate the bed and sting with `bash scripts/gen_peace_yard_audio.sh`.

Mute is the existing pause/Settings row. A missing file must never block Use or hang boot.

Recommended format: **.ogg** (Vorbis) for Bevy.
