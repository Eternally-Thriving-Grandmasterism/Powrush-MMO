## 0. Why this file exists

Core named UI reads **too small / not intuitive on first launch**. A stranger who has not yet walked the yard should be able to enlarge chrome **before** Title, pause, Settings, and the one lived-hour card feel like footnotes.

`LAUNCH_UX` already stamps **Brightness / Text scale** on the same Settings plate after D3. `UI_AND_VFX_DIRECTION` already names **scalable UI**. This file does not invent a second settings surface. It names **when** the control is reachable, **what recommended defaults** mean, and **what scale must not become**.

Compare thoughtful AA chrome hygiene (Wildstar / WoW **readable plates**, contrast, and size that survives a living world) **without** borrowing their teacher. Raid calendar, auction gold, ability-bar / F-row, race lobby at character select — refused by `FUN_WITHOUT_WOW`. Scale is hygiene, not a class kit.

## 1. First-launch / early Settings — scale with recommended defaults

**When:** Title **Settings** (S0) and the same opaque Settings plate from pause / Digit3 (`LAUNCH_UX` D1–D2, After-D3 comfort). First run is still **offline**. The stranger may open Settings from Title **before** Hands, enlarge chrome, then Play.

**What:** One **UI / text scale** control on that existing plate — not a new HUD, not a boot wizard, not a second pause. Brightness stays the sibling comfort row already named. Persist beside Grove on `data/powrush_settings.json` when Hands later wires it (this file does not write that JSON).

**Recommended defaults** (names for later Hands; values are intent, not a Cargo claim):

| Preset | Intent | Who it is for |
|---|---|---|
| **Comfort** | Larger type and plate padding. Named rows (Play / Continue / Settings, pause Resume / Title / Quit, lived-hour card) read first. | First launch, Deck / 1280×800, soft GPU, anyone who found the yard tiny. |
| **Standard** | Steward default once Comfort has been tried or declined. Matches current After-D3 Text scale as shipped-feel, not a new look. | Returning House; laptop at a desk. |
| **Compact** | Tighter chrome for high-res / far seating — still one HUD, still hideable by **H**. | Optional; never the first-launch default. |

**First-launch recommendation:** default the **control's recommended pick to Comfort** (or an equivalent larger step of the existing Text scale) so the stranger can enlarge chrome before the yard feels tiny. Compact is never auto-picked on a cold Title. A continuous slider may sit under the three named presets; presets win the sentence.

Title opaque contrast stays law (`LAUNCH_UX` After-D3). Scale may not wash the Title into the climate breath, and may not add a peer count.

## 3. H still hides — scaled chrome must hush

**H wins.** Hide guidance / slabs stays **H** (`INPUT_CANON`, `LAUNCH_UX` D2, `PLACE_CLARITY_HOUR` §3). Settings *Hide slabs* remains the persisted default; **H** still toggles in the session.
