## 1. Purpose

**Settled + book** is the hour's biggest turn: it opens the other three rooms. Today that turn can land as a **list-row teleport**. Rung C asks the same turn to read as a **door**.

Three reads, without a second HUD:

1. **Door** — Settled + book *opens* Places. The plate is a threshold you confirm, not a roster you tap through.
2. **Four rooms on disk** — Sanctuary / Heartwood / Threshold / Depths are save-slots sharing one House (`OFFLINE_SKU`). Not shards on a wire. Not a teleport menu.
3. **Arrival** — leaving one hex and standing in another should land as *arrival in a room*, not a camera cut that forgets the Place.

The climate slab already names Place + well mood (`PLACE_CLARITY_WALK` · Hands `#355` / `#349`). Person-read is rung B (`PERSON_READ_SPEC` · Hands `#360`). Rung C does not replace those. It makes the **leave-from** and **land-in** carry the same honesty.

This is **Presentation** (`STUDIO_ARCHITECTURE_ORDER` layer 3) of travel that already exists (walked U2 / U8.1 / U11). Presentation never writes \(F\), never locksteps pose, never invents Wall-clock as game truth. Hex climate still lives in `powrush_hex_<id>.json` in the U1 user dir. Travel is another file, not a server.

WoW hub clarity is the teacher for **leave-from** (`GDD_IMMERSION_REVISION` §2.2). The auction / race lobby / ability-bar turn stays refused.

Hour 1 does **not** require an instance portal, a loading mural, or a camera rewrite. It requires a stranger, looking at stills, to answer: *did Settled + book open a door?* *are these four rooms on my disk?* *did I arrive?*
