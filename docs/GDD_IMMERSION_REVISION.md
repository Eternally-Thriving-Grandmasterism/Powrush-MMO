## 1. Honest gap — what is actually wrong

Say it plainly, because the ladder is worthless if the gap is flattered.

**The code teachers exist. The screens do not carry them.** Hour 1 is walked and green: one Use verb on the local tick, wells that speak Idle · Glowing · Tended · Resting · Stressed, week as **tons + restored**, four rooms as files on disk (README Agent landing, walked U0–U8 and the stamps listed there). None of that is the problem. The problem is that a stranger looking at a screenshot sees **less than a single-A game**, and four specific reads are the reason:

| Named gap | What a stranger sees | Where it already has law |
|---|---|---|
| **Presentation** | Flat chrome and flat ground. The hour is legible in the code and in the docs, not in the frame. Type and plates read small on a cold Title. | `FIRST_LAUNCH_UI_SCALE` (rung law, Hands pending) · `LAUNCH_UX` After-D3 · `UI_AND_VFX_DIRECTION` scalable UI |
| **Person-read** | Nobody is *standing there*. Bodies do not read as people, and the verb does not read as an action performed by a person — breath and carry exist in `client/src/living_body.rs` and `client/src/human_presence.rs` but nothing on screen says so. | `PLACE_CLARITY_HOUR` §1 (four bodies) · `FUN_WITHOUT_WOW` §1.1 |
| **Settled door** | The **Settled + book** moment that opens the other three rooms is the hour's biggest turn and it lands as a list row. The door does not feel like a door. | `OFFLINE_SKU` Places-after-Settled · `LAUNCH_UX` S3 · U2 travel |
| **Blank climate slab (walk fail)** | The slab can come up **unnameable** — no place word, no well mood — which is exactly the fail row `PLACE_CLARITY_WALK` §4 wrote down. `#349` put the place line on the slab; the walk shots that would prove it are still owed by a human. | `PLACE_CLARITY_WALK` §1 / §4 |

Two of the four are already law with Hands **pending Core** (slab clarity, first-launch scale). Two are unlanded (person-read, Settled door). Nothing below asks for a new system to cover them — it asks which existing surface gets the polish, in what order.

**Hands beat lore.** If a rung cannot be shown in a screenshot or a keypress, it is not on this ladder.

## 3. Phased immersion ladder — docs law only

Ordered rungs. **Each rung waits on the previous rung being confirmed and, where Hands are involved, landed.** No rung is a slice until §5 says CONFIRMED. Paths named below are **candidate touch-points for a later Hands slice**, listed so a build is scoped rather than freestyle — this file writes none of them.

### Rung A — Readable climate slab + first-launch UI scale
**Status:** already law. Hands **YELLOW pending Core**.  
**Ask:** the slab names place + well mood in the first seconds, and a cold Title can be enlarged before the yard feels tiny.  
**Law:** `PLACE_CLARITY_HOUR` · `PLACE_CLARITY_WALK` · `FIRST_LAUNCH_UI_SCALE` (Comfort / Standard / Compact; Compact never the first-launch default).  
**Owed:** the human walk shots from `PLACE_CLARITY_WALK` §3 — Title, Sanctuary slab, Other Place slab, post-**H**. Bots invent no screenshots.  
**Candidate paths:** `client/src/climate_visible.rs` · `client/src/local_settings.rs` · `client/src/settings.rs`.  
**Gate:** Core posts the shots. A fail row in `PLACE_CLARITY_WALK` §4 is the only thing that earns the next feel.

### Rung B — Person-shaped bodies + action reads (the CO gift)
**Rung B law:** `docs/PERSON_READ_SPEC.md` (Core Confirmed `"2 B proceed"` — this rung only; Hands still wait on a named YELLOW SLICE).  
**Status:** **not law.** Proposal. YELLOW Hands **later**, after A's shots.  
**Ask:** a stranger names *a person standing in a room* and can read the action being performed, from a still frame, at Sanctuary's default camera distance. Breath / carry / heavy already exist in sim — make them visible on the body.  
**Scope guard:** one player body read plus the Peace **E** action read. **No art-pack freestyle** — no new mesh set, no texture pack, no animation library, no character creator, no silhouette that implies a class kit or a weapon.  
**Candidate paths:** `client/src/living_body.rs` · `client/src/human_presence.rs` · `client/src/local_player.rs` · `client/src/harvest_feel.rs` · `client/src/feel_move.rs`.  
**Refuse inside the rung:** second Camera3d · F-row · combat pose · gear slots · race silhouette · person mesh on Sanctuary that reads as Heartwood dress.  
**Gate:** Core confirms §3 rung B **and** names the asset budget. Any mesh or texture add is its own named art slice with its own ballot.

### Rung C — Settled + book Other Place door clarity
**Rung C law:** `docs/SETTLED_DOOR_CLARITY.md` (post-`#360` next step — this rung only; Hands still wait on a named YELLOW SLICE).  
**Status:** not law. Proposal.  
**Ask:** the **Settled + book** turn reads as a door being opened, and the Places plate reads as *four rooms on your disk* — not a menu of teleports. Arriving in another room should land as arrival.  
**Constraints:** four rooms and only four. Play still always boots Sanctuary; Continue loads last hex (`OFFLINE_SKU`). Places stays the one dedicated plate above the world; no second HUD, no fifth row, no Market row.  
**Candidate paths:** `client/src/hex_travel.rs` · `client/src/ledger_bind.rs` · `client/src/world_answer.rs`.  
**Gate:** rung A shots landed; Core confirms.

### Rung D — Guild / House logistics (TTD) on credit
**Status:** not law. Proposal, and the largest of the six.  
**Ask:** harvest → refine → ship → manufacture as a House-scale loop whose only score is **tons + restored**, with **credit** (repair-rights via **Reserve**) as the currency story.  
**Hard shape:** not a gold Market. No price, no sell, no ticker, no stall, no auction. Market stays **HOLD** and stays out of the House sum. Every leg must be expressible in the sacred five verbs and must land in the week counters.  
**Order:** after B and C. A logistics chain performed by unreadable bodies in rooms whose doors do not read is not immersion, it is a spreadsheet.  
**Gate:** Core confirms §2.3 and §3 rung D, then a SLICE CARD splits it — one leg per PR, `shared` sim first, client read second.

### Rung E — NPC schedules (Oblivion-grade) without the broken economy
**Rung E law:** `docs/NPC_SCHEDULE_SPEC.md` (post-`#367` D4 allocate @ `459ffcf0` — this rung only; Hands still wait on a named YELLOW SLICE).  
**Status:** docs law. Hands **unbuilt**. **After** persons (B) and logistics (D).  
**Ask:** persons with schedules and work loops on the existing day, performing the same verbs at the same posts, greeting by Place and mood.  
**Hard shape:** no ownership economy, no theft, no fence, no crime meter, no combat between persons, no schedule that can strand the hour. Persons never write the house book and never gate a Place.  
**Candidate paths:** `client/src/living_day.rs` · `client/src/living_ecology.rs` · `client/src/human_presence.rs`.  
**Gate:** Core confirms; acceptance must include *the hour still finishes if every person is removed*.

### Rung F — Vanilla / TBC hub identity as Place dress
**Status:** SPEC landed in `PLACE_DRESS_SPEC` (docs-only). Hands HOLD until Core names a YELLOW SLICE with exact paths. Last rung, on purpose — dress is cheapest to change once the bodies, doors and loops read.  
**Ask:** each Place's palette, material and mood say its name before any slab does, at zone-identity strength.  
**Hard shape:** **still four Places. No fifth. No race select.** No hub vendor strip, no auction corner, no flight-master node, no instance portal. One material per Place — a room needing two materials is a failed read, not an argument for a room.  
**Gate:** Core confirms; any new asset is a named art slice after a playtest note.
